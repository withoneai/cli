# One CLI reference

Every command, flag, default and output shape of the [One CLI](../README.md), by topic. `one guide` prints the same material in the terminal, and `one <command> --help` prints a command's options.

| Page | What it covers |
|------|----------------|
| [Setup](./setup.md) | Installing the CLI, signing in, updating, telemetry and where the CLI keeps its state. |
| [Connections](./connections.md) | Connecting apps, listing them with the access you have on each, and removing them. |
| [Actions](./actions.md) | Finding an action with its documentation, loading more of it, running it, and the local cache. |
| [Flows](./flows.md) | Multi-step workflows that chain actions across platforms. |
| [Memory and sync](./memory-and-sync.md) | The local memory store, and syncing platform data into it. |
| [Relay](./relay.md) | Receiving webhook events and forwarding them. |
| [Connect](./connect.md) | Optional skills, creating a Connect app, and running the CLI for one of its users. |
| [Configuration](./configuration.md) | Access control, the `.onerc` file and the MCP server entries the CLI keeps in step. |
| [Agents](./agents.md) | Agent mode, the built-in guide, onboarding and how the CLI maps to the MCP server. |

On the website: [getting started](https://withone.ai/docs/getting-started), the [CLI page](https://withone.ai/docs/cli), and the guides for [Relay](https://withone.ai/docs/relay) and [Connect](https://withone.ai/docs/connect).
